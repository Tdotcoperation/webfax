# Web Modem REAL v1

브라우저에서 파일을 실제 4-FSK 음성 신호로 변환하고, 다른 기기의 마이크로 받아 원본 파일로 복원하는 실험용 웹앱입니다.

## 핵심 기능
- 전송 / 수신 탭
- 실제 파일 바이트를 4-FSK(900/1300/1700/2100 Hz)로 변조
- 2500 Hz 시작음 + 무음 구간으로 수신 동기화
- 파일명, MIME, 크기 전송
- 수신 후 원본 파일 Blob 복원
- CRC32 무결성 검사
- 일반(20 ms/symbol), 안정적(35 ms/symbol) 모드
- 서버 업로드 없음

## 테스트 순서
1. 반드시 HTTPS로 배포해 사용하세요. (마이크 권한 때문에 로컬 file://보다 HTTPS 권장)
2. 수신 기기에서 `수신` → `수신 시작`.
3. 송신 기기와 수신 기기의 속도 모드를 동일하게 설정.
4. 처음에는 전화 통화 없이 두 기기를 5~15cm 정도 떨어뜨려 직접 테스트.
5. 작은 TXT 파일(예: 20~200바이트)을 선택해 송신.
6. 성공하면 전화 통화 2대 + 송수신용 폰 2대 구조로 테스트.

## 제한
- 실험용 프로토콜이라 잡음이 심한 통화, 블루투스, 강한 노이즈 제거 환경에서는 CRC 오류가 날 수 있습니다.
- 최대 파일은 8KB로 제한했습니다. 음성 데이터 통신은 매우 느립니다.
- 현재 ACK/NACK 자동 재전송 및 오류정정(FEC)은 없습니다.
- 전화 앱/기기에서 노이즈 제거, 에코 제거, 음성 코덱 압축 때문에 전송 품질이 달라질 수 있습니다.

## 배포
정적 파일이라 Cloudflare Pages, Vercel, Netlify 등에 그대로 올릴 수 있습니다.
